# CampusFind — Campus Lost & Found

## Activity 11: Mini Hackathon Prototype

### Problem
Students often lose belongings around campus and have no simple centralized way to report and recover them.

### Solution
CampusFind is a campus Lost & Found platform for browsing, searching, reporting, and claiming items.

### Features
- Browse reported items
- Search and category filtering
- Claim an item
- Submit a lost/found report
- Responsive interface

### Technology
- HTML5
- CSS3
- JavaScript

### Hackathon Retrospective
1. Building and connecting the interface quickly under time pressure was the main challenge.
2. A future version should add a backend/database and real-time item matching.
